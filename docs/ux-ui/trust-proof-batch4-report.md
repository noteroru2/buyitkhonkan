## UX/UI changes

### 1. Replaced illustrative trust gallery with verifiable service information

The homepage no longer relies on the old three-card illustrative trust gallery as the main trust mechanism.

New shared component:

`src/components/TrustProofSystem.astro`

The module shows:

- The buying brand and operating company from central `SITE` data
- Service-area model in Khon Kaen
- Explicit no-walk-in disclosure
- Single LINE / phone / operating-hours identity
- Direct links to About, Contact, and Purchase Terms pages

### 2. Transaction proof sequence

The module explains the buying transaction in four checkpoints:

1. Preliminary assessment before appointment
2. Inspection in front of the seller
3. Final price confirmation before handover
4. Payment after agreement, with purchase evidence

This is intentionally process proof rather than testimonial or decorative proof.

### 3. “What happens after LINE?” timeline

A five-step LINE timeline was added:

1. Seller submits product information
2. Team reviews the information
3. Preliminary price is communicated
4. Appointment is arranged according to queue
5. Inspection, final confirmation, and payment

The LINE CTA uses `data-cta-location` so the existing Base tracking handler can distinguish Trust/Proof conversions from other CTA locations.

### 4. Privacy / document expectation

The system explicitly tells users not to send ID-card images or unnecessary personal documents before the team requests them.

For company / bulk sellers, the system points to the existing document guide instead of duplicating detailed accounting/document content inside every money page.

### 5. Money-page quick navigation

Category and detail Money Page navigation now includes **“ตรวจสอบก่อนขาย”** and jumps directly to the Trust & Proof System.

### 6. Responsive behavior

The component has dedicated breakpoints for:

- Desktop identity / proof grid
- Tablet 2-column proof layout
- Mobile single-column proof layout
- Mobile LINE CTA stacking
- Narrow-phone business facts layout
